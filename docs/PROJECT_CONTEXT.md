# 1. 项目基本信息


## 项目名称

AI Course Agent


## 中文名称

智能课程学习助手 / 教育领域知识智能体


## 项目定位

AI Course Agent 是一个面向大学课程学习场景的大语言模型应用系统。

项目目标不是简单实现：

上传 PDF → 调用大模型 → 返回答案


而是设计并实现一个具有：

- 课程知识库能力
- 检索增强能力
- 任务规划能力
- 学习辅助能力

的教育领域智能体系统。


核心技术：

- RAG（Retrieval-Augmented Generation）
- Agent
- LangChain
- LangGraph
- 大语言模型
- Embedding
- Vector Database

# 2. 项目目标

# 3. 项目背景


## 大语言模型的问题

大语言模型虽然具有较强的语言理解能力，但是在专业课程学习场景中存在：

1. 缺少用户个人课程资料

2. 专业知识准确性无法保证

3. 不理解课程章节结构

4. 无法针对学生目标制定学习计划


因此需要结合：

RAG：

解决专业知识增强问题。


Agent：

解决任务规划和复杂任务执行问题。

# 7. 教育场景优化设计


## 7.1 知识点级 Metadata


普通RAG：

只保存文本内容。


本项目：

保存课程知识结构。


示例：


{
"text":"TCP通过三次握手建立可靠连接",
"course":"计算机网络",
"chapter":"传输层",
"section":"TCP连接管理",
"knowledge_point":"TCP三次握手",
"difficulty":"medium"
}


目的：

让系统不仅根据文本相似度检索，

还能够理解课程知识关系。

# 8. 实验设计计划


项目不仅实现功能，同时进行实验分析。


## 8.1 RAG实验


### 实验1：文本切分策略比较


目的：

研究不同chunk策略对课程问答效果的影响。


实验方案：


Baseline：

固定长度切分


优化方案：

- 章节级切分
- 知识点级切分


评价指标：

- 检索准确率
- Top-K命中率
- 回答质量评分


---

### 实验2：chunk参数实验


变量：

- chunk_size
- chunk_overlap


研究：

不同参数对于检索效果的影响。


---

### 实验3：Embedding模型比较


比较不同Embedding模型。


评价：

- Recall@K
- 检索效果
- 回答准确性


---

### 实验4：Metadata消融实验


比较：

无metadata

VS

加入课程章节和知识点metadata


分析：

课程结构信息是否能够提升RAG效果。


---

## 8.2 Agent实验


目标：

验证Agent相比普通LLM的任务规划能力。


Baseline：

普通LLM生成学习计划。


方法：

RAG增强Agent。


评价：

- 学习计划合理性
- 知识覆盖程度
- 个性化程度
